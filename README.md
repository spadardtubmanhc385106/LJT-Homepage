# LJT-Homepage

Personal academic homepage of **Junteng Liu**, a first-year PhD candidate in Computer Science at the HKUST NLP Group, supervised by Prof. Junxian He. Research on natural language processing and machine learning.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Where the content lives

* `_config.yml` — site-wide settings and the author profile shown in the sidebar (name, bio, affiliation, email, GitHub, Google Scholar, X).
* `_data/authors.yml` — author profile data.
* `_data/navigation.yml` — header menu (About, Publications, CV).
* `_pages/about.md` — the home page: biography, research interests, education, research experience, publications, skills, honors and contact details.
* `_pages/cv.md` — CV generated from the same information plus the publications collection.
* `_pages/publications.html` and `_publications/` — the publications page and one Markdown file per publication.
